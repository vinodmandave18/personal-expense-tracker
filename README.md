# Personal Expense Tracker

A web-based application designed to manage personal income, expenses, and budgets in one place.

## Features

- User Registration and Login
- Income Management
- Expense Management
- Expense Categories
- Admin Dashboard
- MySQL Database Integration
- Secure Password Hashing

## Technologies Used

- Java
- JSP
- Servlets
- HTML, CSS, JavaScript
- MySQL
- JDBC
- Maven
- Apache Tomcat 9
